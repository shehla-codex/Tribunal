# Tribunal: Demo Video Script

**Length:** about 2:15 min | **Format:** screen recording, on-screen captions and music, no voiceover
**Live app:** https://tribunal-silk.vercel.app | **Mode:** Demo Mode only (fully offline, same result every time)

## Recording Rules

- Record each scene as a separate clip. Redo only the clip with a mistake.
- Use the SQL Injection demo case throughout.
- Browser zoom 100%, one tab only, bookmarks bar hidden, notifications off.
- Laptop speakers on, so the gavel sound is recorded.
- Let the debate animation play (do not skip), and keep the debate box tall enough that no text is cut off.
- Always call the judge "Chief Justice Owl".

## Editing (CapCut)

1. Put clips on the timeline in order.
2. Add captions with Text (short, 2-4 seconds each).
3. Add a royalty-free cinematic track from CapCut Music at 20-30% volume.
4. Export 1080p MP4, then upload to YouTube as Unlisted.

## Do Not Use

No Ace Attorney or Capcom assets, music or characters.
